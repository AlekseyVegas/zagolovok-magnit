# Заголовок-магнит

Придумывает заголовки для статей, постов и тем писем на русском языке: пять сильных вариантов под разные углы, с разбором лучшего и парой для A/B-теста.

Обычно ИИ предлагает пять одинаковых заголовков с одной и той же конструкцией. Заголовок-магнит берёт пять разных углов (выгода, интрига, цифры, личный опыт, боль), проверяет каждый по формуле 4U и честно говорит, какой выбрать и почему. Заголовок обещает только то, что есть в тексте.

Автор: Алексей Пономарев, маркетолог.

## Что внутри

**Старт** (`start`). Проводит через первый запуск и сразу даёт результат: достаточно прислать тему или текст статьи.

**Заголовки** (`zagolovki`). Собирает вводные, подбирает углы, пишет пять вариантов с пометкой угла, проверяет каждый по 4U. Выдаёт пять вариантов, лучший с объяснением, пару для A/B-теста и подзаголовок. Учитывает площадку: Дзен, VC, блог, рассылка, Telegram.

**Проверка 4U** (`proverka-4u`). Берёт ваш готовый заголовок, оценивает его по четырём пунктам (польза, конкретика, срочность, уникальность), проверяет длину и честность и предлагает пять улучшенных вариантов.

## Быстрый старт

Откройте новый чат с Claude и напишите «С чего начать с Заголовком-магнитом?» или просто пришлите тему статьи в одном предложении.

Примеры запросов:

- «Придумай заголовок для статьи на Дзен: как самозанятому разделить личные и рабочие деньги»
- «Вот текст статьи, дай варианты заголовка и подзаголовка»
- «Проверь мой заголовок: …»
- «Тема письма для рассылки про запуск курса, до 45 знаков»

## Принципы

- Не выдумывает цифры, сроки и результаты: только то, что есть в вашем тексте.
- Без КАПСА и кликбейта вроде «вы не поверите» для Дзена и VC.
- Пять разных углов вместо десяти однотипных вариантов.

## Данные и безопасность

Плагин состоит только из текстовых инструкций. Он не запускает программы, не подключается к внешним сервисам и никуда не отправляет ваши тексты.
